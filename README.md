# Crafttech Rich Text Test

Этот проект представляет собой элемент canvas, который занимает всю ширину экрана и построен с использованием библиотек Konva и React-Konva.

## Функционал

Проект включает в себя следующие функции:

1. **Взаимодействие** - позволяет перемещать фигуры и сам canvas. При клике на фигуру открывается/закрывается текстовое поле ввода.
2. **Добавление** - позволяет добавлять новые фигуры по клику.

## Установка

Для установки зависимостей выполните команду:

```sh
npm install

```
## Запуск проекта
Для запуска проекта в режиме разработки выполните команду:
```sh
npm run dev

```
Для сборки проекта выполните команду:
```sh
npm run build

```

## Структура проекта
Проект использует следующие библиотеки:
    1. [Konva](https://konvajs.org/)
    2. [React-Konva](https://konvajs.org/docs/react/)
    3. [React-Quill](https://github.com/zenoamaro/react-quill)
    4. [html2canvas](https://html2canvas.hertzen.com/)

## Задачи
1. Добавить стили для компонентов.
2. Типизировать проект.
3. Добавить текстовый редактор. При открытом поле ввода должно появляться меню, позволяющее изменить текст (сделать жирным, поменять размер шрифта, цвет и т.п.). После закрытия поля ввода, введенный текст должен отобразиться на canvas как картинка в том же месте фигуры, сохранив при этом все стили.

## Обязательные требования
1. Сохранение текущего функционала. Перемещение canvas, фигур и ввод текста должны быть обязательно.
2. Использовать препроцессор SASS/SCSS.
3. Проект не должен содержать any.
4. Проект должен билдиться.
